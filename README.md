# 像素 MG · Xiangsu MG

**像素 MG 的完整源码已经开源，并迁入新的统一仓库：**

## [前往像素·绿宝石 & 像素 MG 开源仓库](https://github.com/maverickgao8848/xiangsu-lvbaoshi)

新仓库包含像素 MG 完整 Skill、青柠玻璃与白金等风格资源，以及像素·绿宝石口播包装 Skill。自有代码与文档采用 MIT 许可，允许商业使用、修改和再分发；字体、参考素材与其他上游资源仍遵循各自条款。首次安装请阅读新仓库的 [INSTALL.md](https://github.com/maverickgao8848/xiangsu-lvbaoshi/blob/main/INSTALL.md)，也可以把该页交给 AI 助手完成环境部署。

像素 MG 把中文讲解、带时间码的口播与分镜参考制作为可编辑的 HyperFrames 知识动画，适合解释流程、关系、对比和机制。
