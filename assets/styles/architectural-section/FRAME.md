# 建筑剖面轴测 · 三维意境

Style ID：`architectural-section`。用户在六种静态提案中选择保留建筑方向；已确认范围为静态视觉。参考 `samples/knowledge-building.png` 的空间、材质、字形和物件融合方式，具体楼层、内容与路线按本期知识关系设计。

## 视觉意图

把知识过程放进一座可以剖开观察的建筑：楼板区分阶段，房间容纳对象，楼梯和跨层连接呈现先后、依赖或流转。观众能在同一空间里辨认局部与整体。柔和日光、浅色实体墙、橡木操作台和原色白瓷形成安静的模型世界。

## 颜色与材料

| 角色 | 色值与表现 |
|---|---|
| 背景 | `#e6e8e0`，淡灰绿空场 |
| 主文字 | `#343d37`，深灰绿 |
| 次级文字 | `#69796f` |
| 墙体 | `#e9e5dc`，暖灰白粗糙面 |
| 楼板 | `#e0dfd5`、`#d7c09d`、`#ced7c7`，按层区分浅灰、木色与灰绿 |
| 木台 | `#ad9270` 侧面与 `#e5c497` 台面 |
| 环境植物 | `#648271`，低饱和绿 |
| 当前流转路径 | `#b36840`，细赭色线 |

使用粗糙实体面、细结构边、接触阴影和一致的柔日光。明暗来自模型表面与灯光；主要阅读面清晰，阴影保留层间关系。

## 字体与构图

中文短命题使用本地 Noto Serif SC 900，解释与标签使用 Noto Sans SC 500–700。字体及 OFL 随包提供：

- `assets/references/styles/architectural-section/fonts/noto-serif-sc.ttf`
- `assets/references/styles/architectural-section/fonts/noto-sans-sc.ttf`

1920×1080 静态起点：主命题约 100px，楼层标签 38px，解释 26–34px。按实际文字与景别调整。

总览让建筑占据主要画幅，短命题与必要说明放在空场；标签靠近对应楼层或操作面。局部解释可进入一个房间或剖面，把正在变化的对象与相关结构同时留在阅读窗。楼层数量、左右关系和建筑形状由知识结构确定。

## 几何与物件接口

楼板、墙、台阶、操作台和必要内部空间使用真实三维几何。总览采用正交投影与低角度斜视，保留楼板厚度和可观察的房间进深；剖去朝向镜头的遮挡面，露出本期操作位置。

具体实体按 Skill 的 `references/object-library.md` 取得 Pixel2All 图片，保留原色白陶瓷。单图可作为朝向阅读视点的展品平面或 billboard；需要换面或进入内部的主体准备相应几何或连贯多视角素材。连接、过程路径及内部结构使用项目可控几何。

示例中的“资料库—检索层—回答层”用于演示空间关系。本期房间的用途、路径、数量和文字来自本期文稿。

## 动作性格与验证

可以沿楼层升降、从房间拉远到建筑总览，或跟随对象经过相邻操作面。保留对象身份、楼层地标与可读落点，路径和物件状态一起体现知识关系；具体时序、文字编舞及 seek 接口沿用 Skill 的 `references/motion-direction.md`。

静态样图已经用户选定。后续制作先验证本题最关键的跨层交接或内部观察，再扩展时间轴；动画、声音和内容替换的结果记录到本期工程。
