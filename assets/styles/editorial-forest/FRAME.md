# Editorial Forest — 中文教学 MG

## 视觉意图

让知识对象成为一页会发展的编辑插画：大衬线命题与主题图形互相解释，森林绿、灰粉和奶油纸形成统一材料世界。构图随教学关系变化；材料年轮是储热主题的例子，不是通用图形模板。

## 色彩与纸面

| Token | 值 | 用途 |
|---|---|---|
| green | #2e4a2a | 主墨色、重要命题的深色纸面 |
| green-deep | #243a21 | 粉色底上的文字 |
| green-lite | #3a5a36 | 同族次级图形 |
| pink | #e89cb1 | 重点、状态变化、编辑转场 |
| pink-deep | #d27e96 | 同族次级强调 |
| cream | #efe7d4 | 默认纸面、深色底正文 |
| cream-2 | #e6dcc4 | 次级纸面 |
| ink | #1a1a17 | 浅色底正文 |

每个稳定画面选择一个主纸面和一个次级色块；图形和文字使用上表墨色。深度来自色块、填充与轮廓关系，保持平面纸感。场色可在语义转折时插值切换。

小字用 cream-on-green、green/ink-on-cream 或 green-deep-on-pink；粉绿相配优先留给大字与图形，实际对比检查决定是否可用。

## 字体与层级

采用获选中文候选的可复现字体组合：**Noto Serif SC Variable** 承担中文与正文，**DM Mono 400** 承担拉丁编辑标注；中文标注回退到同一 Noto Serif SC。显示文字 weight 500，正文 400。依赖须在构建时准备为本地字体文件，加载完成后再采样；本风格包只携带规范与参考图，不携带字体二进制。

1920×1080 基准：主标题约 84–140px，主要结论 55–82px，解释文字 30–36px，辅助标注 20–26px。按实际中文长度调整；承载教学信息的文字至少 27px，较小 mono 仅用于非关键编目标注。显示字紧凑行距约 0.98–1.12；正文约 1.38–1.42；中文避免套用英文词数分档。

这些区间是构图起点；以实际字形、可读性与主次关系决定最终值。

## 构图与图形

在画面约 96px 内边距组织内容。容器使用 container-type: size；相对尺寸使用 cqw/cqh，固定画布可用 px。

用一个主题插画、一个命题或一个真实数量关系建立主焦点；说明与标注围绕它布置。可采用插画与命题对开、整页大命题或关系过程展开，根据脚本选择。让重复出现的对象保持语义，改变视角、大小和留白来发展解释。

顶部采用轻量编辑标签与细线；封面、数据或结论页可加页脚。主题章印可放在需要定位章节的镜头；字符来自当前内容。界面标注为教学主体让出空间。

编辑分隔线为 2px；如采用步骤卡边框可用 2.5px，卡片圆角为 6–8px。语义图形的线宽按主次和实际大小调整：获选例使用约 1.5–2.4px 轮廓、4px 路径。圆形可用于章印，也可表达环、粒子、节点等真实关系。

参考图用于构图、字体角色和纸面完成度；图内文案、品牌和数量不是新项目的内容来源。

## 运动性格

编辑式色带、命题落版与场色切换可用于机制转折；色块边缘、纸面轮廓和章印可成为空间地标。共享 motion-direction 决定镜头与交接，平面纸感保留在材料表现中。

动作时点由当前旁白和教学事件决定。获选例的储入、停驻、反向释放只解释热量存储，不提供固定秒数或所有主题必须采用的动作序列。时间驱动与质量门禁使用 Skill 现有契约。
